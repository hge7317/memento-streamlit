# MEMENTŌ · Streamlit 면접 복기

빠른 메모 → 기억 확인 → 대화형 복기 → 최종 검토 → 노트 다운로드.
과제용 접속 비밀번호는 `pnumis`입니다.

## 실행

Python 3.11 이상을 권장합니다. 터미널에서 이 폴더로 이동한 뒤 실행합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run app.py
```

Mac에서는 `시작.command`를 더블클릭해도 됩니다. 최초 실행에는 패키지 다운로드를 위한 인터넷 연결이 필요합니다.

## Gemini 연결 (기본 선택)

1. 비밀번호 `pnumis`로 접속한 뒤 왼쪽 사이드바를 펼칩니다.
2. **Gemini 연결**에서 비공개 API 키 입력창에 키를 붙여넣습니다.
3. **Gemini 연결 확인**을 누릅니다. 이 검사는 `connection test` 예시 문장만 전송합니다.
4. 성공 메시지를 확인하고 메모 전송 동의를 체크하면 Gemini를 사용합니다.
5. 기본 모델은 `gemini-3.5-flash-lite`이며, AI Studio의 프로젝트에서 사용 가능한 무료 지원 모델로 바꿀 수 있습니다.

API 키는 채팅이나 GitHub에 공유하지 않습니다. 화면에 입력한 키는 현재 세션에서만 유지되며 새 복기 시작/로그아웃 시 삭제됩니다. 서버에서 사용하려면 `.streamlit/secrets.toml.example`을 참고해 `GEMINI_API_KEY`, `GEMINI_MODEL`을 설정합니다. 같은 이름의 환경변수도 지원합니다.

무료 티어 여부는 Google 프로젝트와 모델 설정에 달려 있습니다. 앱은 무료 여부를 자동 판정하거나 과금 설정을 바꾸지 않습니다. 호출 한도 초과 시 안내 후 기본 모드로 전환할 수 있습니다. 무료 티어의 데이터 이용 조건을 확인하고 과제 시연에는 가상 내용을 사용하세요.

공식 모델/무료 티어: https://ai.google.dev/gemini-api/docs/pricing
공식 API 명세: https://ai.google.dev/api/generate-content

Gemini 호출 경로, JSON 응답, 한도 초과, 미완성 응답, 전송 동의와 키 초기화는 모의 응답으로 검증했습니다. 실제 키를 이용한 연결 검사는 앱에서 직접 실행해야 합니다.

## OpenAI 연결

1. 비밀번호로 접속합니다.
2. 왼쪽 사이드바를 펼치고 **OpenAI 연결**을 선택합니다.
3. API 키를 비공개 입력창에 붙여넣습니다. 채팅으로 공유하지 마세요.
4. 계정에서 사용 가능한 모델 이름을 입력합니다. 초기값은 `gpt-4.1-mini`이며 접근 권한에 따라 변경할 수 있습니다.
5. OpenAI 전송 동의를 체크하고 복기를 진행합니다.

서버 설정으로 연결하려면 `.streamlit/secrets.toml.example`을 참고하여 `.streamlit/secrets.toml`을 만들고 실제 키를 입력합니다. 실제 secrets 파일은 GitHub에 업로드하지 않습니다. 환경변수 `OPENAI_API_KEY`, `OPENAI_MODEL`, `APP_PASSWORD`도 지원합니다.

AI 연결 시 메모 분류 및 질문 선택에 Responses API를 사용합니다. OpenAI 요청은 `store=False`이며 앱 자체에서는 파일이나 데이터베이스에 대화를 저장하지 않습니다. 이것이 API 제공자의 모든 로그 보관을 없앤다는 의미는 아닙니다. API 호출 비용은 연결된 키의 계정에 발생합니다. 현재 세션당 최대 12회 호출하며 새 복기를 시작하면 초기화됩니다.

## 사용법

- 기억 항목마다 줄을 바꾸어 입력합니다. ‘아마’, ‘순서를 모름’ 등 불확실 표현도 함께 남깁니다.
- 기억 확인에서 각 항목을 **맞음 / 아님 / 불확실 / 수정**으로 확인합니다. 분류와 문장을 직접 바꿀 수 있습니다.
- AI 분류는 초안입니다. 같은 줄에 사실과 감정이 섞여 있으면 항목을 수정하고 최종 검토에서 별도 항목을 추가합니다.
- 면접 정보는 대화 화면의 접힌 영역에서 선택적으로 입력합니다.
- 대화는 최대 6개 질문입니다. 질문을 건너뛰거나 언제든 최종 검토로 이동할 수 있습니다. 두 번 연속 모름/건너뛰기이면 추가 질문을 멈춥니다.
- 추가 회상 답변도 최종 검토에서 확인해야 노트를 완성할 수 있습니다.
- ‘아님’ 항목은 후속 AI 질문 선택과 다운로드 결과에서 제외됩니다.
- 완성한 노트는 일반 텍스트(.txt) 또는 Markdown(.md) 파일로 다운로드합니다. 텍스트는 한글 호환을 위해 UTF-8 BOM으로 저장합니다. 결과는 사건 시간순이 아니라 검토한 기억 항목 목록입니다.
- 새 복기 시작과 로그아웃은 현재 세션의 메모, 키, 대화 기록을 초기화합니다. 이미 완성한 노트의 브라우저 보관함은 유지됩니다.

## 기본 모드와 AI 모드

기본 모드는 줄·문장 단위 분리와 간단한 단어 규칙으로 초안을 분류하고, 정해진 열린 질문을 차례로 표시합니다. AI를 호출하지 않습니다.

AI 모드는 같은 원문 단위를 AI로 분류합니다. AI가 원문에 없는 내용을 반환하면 기본 처리로 대체합니다. 불확실성과 감정 표현은 보수적으로 유지합니다. 자유로운 질문 생성 대신 허용된 질문 목록에서 다음 질문 ID를 선택하므로, 질문에 새로운 사건 내용을 넣을 수 없습니다. 모든 분류에는 사용자 검토가 필요하며 기억의 정확성을 보장하지 않습니다.

## 제출 링크 배포: Streamlit Community Cloud

이 폴더의 소스만 별도 GitHub 저장소에 올립니다. 상위 작업 폴더나 개인 자료는 함께 올리지 않습니다.

1. Streamlit Community Cloud에 로그인합니다.
2. Create app에서 GitHub 저장소와 브랜치, 진입 파일 `app.py`를 지정합니다.
3. Advanced settings의 Secrets에 아래 설정을 입력합니다.

```toml
APP_PASSWORD = "pnumis"
OPENAI_API_KEY = "실제 키"
OPENAI_MODEL = "gpt-4.1-mini"
```

4. 배포 후 발급된 `https://…streamlit.app` 링크에서 비밀번호와 전체 복기 흐름을 확인합니다.
5. 제출 PPT와 PDF에 실제 링크와 비밀번호를 넣습니다.

현재 소스 구현에는 공개 배포 링크가 포함되어 있지 않습니다. 로컬 주소는 본인 컴퓨터에서만 접속할 수 있습니다. Streamlit은 Python 서버 실행이 필요하므로 정적 사이트 호스팅으로 대체할 수 없습니다.

공식 배포 안내: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy
공식 Secrets 안내: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/secrets-management
공식 API 안내: https://developers.openai.com/api/reference/python/resources/responses/methods/create

## 검증

```bash
python -m pip install pytest
python -m pytest tests -q
```

비밀번호, 필수 검증, 대화와 조기 종료, 최종 노트, 초기화를 AppTest로 확인합니다. AI 내용 변조와 거절 항목 배제는 모의 API 응답으로 검증합니다. 실제 API 연결과 모델 접근은 사용자 키를 설정한 후 별도로 확인해야 합니다.

## 이번 구현 범위

텍스트 입력, 분류·검증, 제한된 비유도 대화, 검토, Markdown 다운로드, 세션 초기화. 사진 인식, 준비자료 대조, 장기 보관과 휴지통, PDF 노트 생성은 포함하지 않습니다. 과제 제출용 PPT/PDF 사용 설명서는 앱의 공개 배포 링크를 확정한 후 별도 제작할 수 있습니다.

## 화면 PRD 반영 업데이트

- 나눔스퀘어 네오(제목)와 Pretendard(본문·버튼)를 웹폰트로 동봉했습니다. 참고: https://yeosungan.leems060811-d7b.workers.dev/
- 홈은 영화 포스터의 분절 구도에서 착안해 `#90A3B4`·`#DBEEFF` 블루 계열 세로 조각, 얇은 memento 워드마크, 두 뉴런의 신호로 구성했습니다. 포스터 사진을 사용하지 않고 Canvas로 새 추상 그래픽을 만들었습니다. 마우스 위치에 따라 세로 조각이 다르게 이동하며, 한곳에 머무르면 약 3초에 걸쳐 자연스럽게 정렬됩니다. 다시 움직이면 새로운 배열로 흩어집니다. 별도의 홈 조작 버튼은 없습니다.
- `prefers-reduced-motion`을 반영하며, 페이지가 보이지 않거나 마우스가 홈 밖에 있을 때 불필요한 애니메이션을 멈춥니다.
- 후보는 카드별로 원문, 분류, 확인 상태를 표시합니다. 맞아요/불확실/수정/내용 없음으로 확인하며, 제외 후 다시 수정할 수 있습니다.
- 검증 완료 요약 후 면접 기본 정보를 선택적으로 입력합니다.
- 회상은 맥락 → 자유 서술 → 단서 → 역순 순서로 진행합니다. AI가 역순 회상으로 먼저 건너뛰지 못하게 제한했습니다.
- 최종 검토에서 기억 순서를 직접 지정할 수 있습니다. 0은 순서 미상이며 AI가 순서를 추정하지 않습니다.
- 결과는 요약/기억 순서/평가·불확실/전체 노트 탭으로 나눕니다.
- 홈 화면 보기는 현재 복기 내용을 유지합니다. 회원 로그인은 확장하지 않았으며, 완성한 노트는 브라우저 보관함에 자동으로 저장합니다.

글꼴 출처: https://campaign.naver.com/nanumsquare_neo/ 와 https://github.com/orioncactus/pretendard

뉴런 그래픽은 #90A3B4와 #DBEEFF를 중심으로 구성합니다. 페이지 바깥 배경은 흰색이며 로그인 폼의 박스 테두리는 없습니다.


## 같은 브라우저의 자동 보관함

완성한 복기 노트는 브라우저 localStorage에 자동 보관됩니다. 상단 Deploy 오른쪽의 **복기보관함**에서 이전 노트를 검색하고 열거나 TXT로 내려받을 수 있습니다. API 키와 비밀번호, 미완성 대화, 제외한 원문은 보관함에 저장하지 않습니다. 저장 대상은 완성 노트, 제목, 작성/수정 시각과 임의 기록 ID입니다.

- 별도 계정이나 IP, API 키로 사용자를 구분하지 않습니다.
- 같은 브라우저 프로필과 같은 사이트 주소(origin)에서만 공유됩니다. localhost의 포트가 바뀌어도 별도 보관함입니다. 공개 배포 주소로 옮기면 로컬 보관함이 자동 이전되지는 않습니다.
- 새 복기 시작, 로그아웃, 새로고침 뒤에도 완성 노트는 남습니다. 복기 중간 내용은 자동 복구하지 않습니다.
- 같은 노트를 수정하여 다시 완성하면 해당 노트를 갱신하며, 매번 중복 추가하지 않습니다.
- 기록별 삭제 확인을 거쳐 삭제합니다. 삭제한 노트는 기존 완료 화면을 열어도 자동으로 재생성하지 않습니다.
- 브라우저 데이터 삭제, 시크릿 모드 종료, 브라우저의 저장 공간 정리 등으로 사라질 수 있으므로 중요한 노트는 TXT로 내려받습니다.
- 저장이 차단되거나 용량이 부족하면 실패 메시지를 표시합니다. 실패한 노트가 보관되었다고 안내하지 않습니다.
- 이전 보관함 전체를 서버나 Gemini로 전송하지 않습니다. 보관함은 브라우저에서만 조회합니다.
